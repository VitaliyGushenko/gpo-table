description: Самопроверка фронта ias — tsc, lint, prettier, свежесть кодогена, типы спеков.
---

Загрузи скилл `dev` (раздел «Самопроверка») и выполни самопроверку фронта. Все команды — из `src/client/ias`:

1. `npx tsc --noEmit -p tsconfig.app.json` — типы TS (шаблоны это не проверяет).
2. `ng lint` — линт; если менялось немного файлов, достаточно затронутых.
3. `npx prettier --check <изменённые файлы>` — формат (список файлов возьми из `git status --porcelain` / `git diff --name-only`).
4. `npm run verify:codegen` — свежесть сгенерированного кода.
5. Если менялись `*.spec.ts` — `npx tsc --noEmit -p tsconfig.spec.json`.

$ARGUMENTS

Итог — сводка одной таблицей: проверка / статус / первая ошибка с путём. Не исправляй найденное без отдельной просьбы: сначала доложи.
