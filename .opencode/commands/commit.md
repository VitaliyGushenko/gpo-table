---
description: Коммит (и пуш) по регламенту скилла commit.
---

Загрузи скилл `commit` и скоммить изменения строго по нему: номер задачи из имени ветки, тег `[add]/[edit]/[refactor]/[gen]`, текст по-русски, сообщение одной строкой через `git commit -m` (в шелле OpenCode на Windows heredoc недоступен), конкретные файлы в `git add` (не `-A`), после коммита — push (если пользователь не отложил пуш).

$ARGUMENTS

Если изменения распадаются на несвязанные логические части — предложи разбивку на несколько коммитов до выполнения.
