---
description: Синхронизировать зеркало .opencode/skills с .zcode/skills.
---

Зеркалируй `.zcode/skills` → `.opencode/skills` (точная копия, с удалением лишнего). Из корня репозитория:

```bash
node .zcode/hooks/sync-skills.mjs --force
```

Скрипт синхронизирует по умолчанию только при переданном на stdin JSON с путём в `.zcode/skills`; флаг `--force` выполняет синхронизацию безусловно. После выполнения покажи, какие скилы изменились в зеркале (сравни списки каталогов до/после).

Важно: в OpenCode хука `PostToolUse` нет, поэтому после правок в `.zcode/skills` эту команду нужно запускать вручную. В zcode та же синхронизация происходит автоматически при каждой правке файлов в `.zcode/skills`.
