# CHANGELOG

## 0.4.0

- Встроенная первая колонка действий «⋯» с пунктами «Редактировать» и «Удалить».
- Действия подключаются сервисом через токен `REGISTRY_TABLE_ACTIONS`, без россыпи входов.
- `isEdit` — единое право на редактирование и удаление; без провайдера колонка не рисуется.

## 0.3.0

- Изменение ширины колонок перетаскиванием и с клавиатуры.
- Сохранение ширин в `localStorage` по `storageKey`; сброс через `resetColumnWidths()`.
- `isResizable: false` исключает колонку из resize.

## 0.2.0

- Динамическая высота области таблицы: считается до низа окна с учётом шапки, футера и слота под таблицей.
- `bottomOffset` — отступ снизу для padding страницы или внешнего футера.
- Горизонтальный скролл включается только через `scrollWidth`.
- При малом числе строк таблица не растягивается: ограничение работает как `max-height`.
- Сортировка в стиле Ant: две стрелки видны всегда, активная подсвечивается фоном.

## 0.1.0

- Контейнер `app-registry-table` на сигналах: загрузка страниц, состояния, слоты.
- Компоненты `head`, `body`, `row`, `foot`.
- Колонки `text`, `number`, `date`, `template`; шаблоны через `registryCell`.
- Пагинация, сортировка, агрегаты, защита от гонок запросов.
- Адаптеры `swaggerGridifyDataSource` и `staticGridifyDataSource`.
- `buildRegistrySearchFields` — поля расширенного поиска из колонок.
- Демонстрационная страница и тесты вычислительной логики.
