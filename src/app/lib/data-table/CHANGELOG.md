# CHANGELOG

## 0.1.0

- Контейнер `app-registry-table` на сигналах: загрузка страниц, состояния, слоты.
- Компоненты `head`, `body`, `row`, `foot`.
- Колонки `text`, `number`, `date`, `template`; шаблоны через `registryCell`.
- Пагинация, сортировка, агрегаты, защита от гонок запросов.
- Адаптеры `swaggerGridifyDataSource` и `staticGridifyDataSource`.
- `buildRegistrySearchFields` — поля расширенного поиска из колонок.
- Демонстрационная страница и тесты вычислительной логики.
